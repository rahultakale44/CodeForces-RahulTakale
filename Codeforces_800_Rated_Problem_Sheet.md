## Recommended Solving Method

1. Read the problem carefully.
2. Try independently for 20–30 minutes.
3. Dry-run sample test cases.
4. Check only the required hint.
5. Write the solution yourself.
6. Submit on Codeforces.
7. Save the accepted solution in the corresponding folder.
8. Commit and push it to GitHub.

## Java File Naming

For local VS Code practice, use descriptive class names:

- `Watermelon.java`
- `NextRound.java`
- `DominoPiling.java`

For direct Codeforces submission, the class name should be:

```java
public class Main {
    public static void main(String[] args) {
        // solution
    }
}
```
